👑 欧陆百合风云 (EU4: Yuri Harem Universalis) 规则手册 👑

> **基本设定**：本作角色**没有寿命**——所有角色不会衰老、不会自然死亡，即使时间流逝一百年，她们依旧如初。因此不存在统治者换代；若历史事件需要，继承危机可作事件使用，但本作暂不涉及。

> **设计原则：机制按统治者性格设计（性格驱动）**——每位统治者的性格决定她在事件 / 战争 / 后宫中的行为逻辑与专属机制。

> **核心设定约束（创作必守，源自核心设定集）**：
> - **着装美学**：乳窗 / 前贴 / 无内裤 / 无胸罩（乳贴）/ **着衣性行为**（不脱衣）/ 禁吊带袜
> - **常驻性玩具**：乳贴 / 肛塞 / 单侧腿环
> - **扶她魅力**：扶她角色大方展示、撸管自慰是日常
> - **侍奉傾向**（-50~+50）：后宫 / 调教的核心数值
> - **生活备忘录**：口交慢玩为主、淑女自慰（ASMR）、清洁感与体液管理
> - **色情行为字典**：侍奉役 / 辅助役 / 拟似竿役 / 打扫口交 / 标准性交
> - **描写规范**：禁非人感刻板描写 / 禁哭腔 / 禁刻板娇喘

第二章：后宫封建制 (The Feudal Harem System)

本游戏的核心机制！国家间的封建从属关系，本质上就是一层层嵌套的后宫体系，这些后宫则是纯女性。

### 1. 后宫编制 (Harem Composition)

每位统治者都拥有自己的直属后宫，容量固定为 **5 人**，通常为「五役各一」：

| 役 | 角色 | 功能与色情定位 |
|------|------|------|
| 武 | 杂鱼骑士 | 上阵战斗、战败被俘、Battle Fuck（败者臣服） |
| 侍 | 女仆 | 日常服侍、贴身侍奉（主仆） |
| 圣 | 修女 | 宗教、忏悔、堕落调教（禁忌反差） |
| 艺 | 舞娘 | 百合表演、宫廷娱乐（舞台诱惑） |
| 秘 | 巫女 | 凯尔特异教、治疗占卜（自然野性） |

构成可按文化组/政体微调（塞壬国偏歌姬、凯尔特氏族偏巫女），但总数固定为 5。

### 2. 嵌套法则 (Nesting Rule)

如果 A 国是 B 国的附庸，那么 A 国的统治者就自动成为 B 国统治者后宫中的「高级玩物」；而 A 国统治者本人仍拥有自己的直属后宫与下级附庸。整座封建金字塔即后宫金字塔。

- 案例说明：奥地利公主（宗主）> 波西米亚公主（附庸）> 摩拉维亚/西里西亚公主（二级附庸）。在外交场合或宫廷宴会上，摩拉维亚和西里西亚的公主必须作为波西米亚公主的后宫成员，在奥地利公主面前进行百合表演；而波西米亚公主本人，也会被奥地利公主搂在怀里肆意玩弄。

### 3. 角色负担管理 (Character Card Budget)

后宫成员**不是**独立有名角色——它们是引擎数据，不占角色卡，以控制上下文负担：

- 每位领主卡内以「后宫概况」简述 5 人构成与锚点钩子（谁最受宠、谁藏着秘密等）
- 玩家点名某成员时**按需生成**（名字/外貌/性格），并回写引擎数据库保持记忆一致
- 重要领主可配 1~2 名预设「宠姬」为有名角色；次要领主纯概况
- 玩家初始国家的 5 人**开局预设**；AI 领主 5 人开局程序生成

### 4. 附庸类型与国际组织

**附庸类型（层级从属）**：

| 类型 | 关系 | 例子 |
|------|------|------|
| **封臣附庸（Feudal Vassal）** | 全从属：纳贡、出兵、战时随征；统治者是宗主后宫的高级玩物 | 约克公爵领 / 诺森伯兰 / 威斯特摩兰 对英格兰 |
| **自治藩属（Autonomous Vassal）** | 高度自治、承认宗主权 | 威尔士对英格兰；群岛领地（名义臣服）对苏格兰 |
| **进贡国（Tributary）** | 仅纳贡、松散 | 待定 |
| **受保护国（Protectorate）** | 受保护、内政自主、外交军事受节制 | 曼岛（英格兰保护下） |
| **采邑主教区（Prince-Bishopric）** | 教会领地附庸 | 达勒姆 |

**国际组织（平等关系，非附庸）**：

| 类型 | 说明 |
|------|------|
| **联合统治（Personal Union）** | 一国公主成为另一国后宫成员（**同处一个后宫**），两国独立、关系松散、非国家从属；本作核心关系之一。**可与附庸关系共存**：独立国家公主可与另一国（含其附庸）的统治者联统，使该统治者同时处于宗主后宫与联统方后宫（共享/双重后宫） |
| **爱尔兰至高王国（High Kingdom of Ireland）** | 平等至高王国（爱尔兰诸部），至高王牵头 |
| **海盗联盟（Pirate League）** | 平等海盗同盟（群岛领地 / 奥克尼 / 设得兰），共享战利品、按功勋分配 |

> 注：**盟友不是常设国际组织**——盟友通过在**外交博弈**中加入某方而形成（博弈期站队、战时并肩），结束后即散，无需单独的盟友组织。

> **联合统治（机制）**：多成员国际组织——**1 个主导国 + 若干被联统国**，共同组成一个后宫。**各成员的原有附庸 / 宗主关系不变**；**主导国可变更**（一般经 LLM 对话决定）。联合统治形成**共享后宫关系**，并在外交博弈、其他国际组织上产生联系——但**非强制**，仅作参考内容（主要由 LLM 酌情考虑）。后期可扩展更多功能，现从简。

> **爱尔兰至高王国凝聚力**：联盟有**凝聚力**值。
> - **提升方式**：主要靠至高王举办**淫趴 / 淫乱节日**（需花费金币）；辅以——共同祭祀节庆（Beltane / Samhain 等凯尔特火节）、战利品共享（劫掠 / 战争胜利后分赃）、**部落间联合统治**（联姻结亲 = 部落之间结成联合统治、互入后宫联姻，每增加一名联合统治成员 → 凝聚力提升）、联盟之仪（换妻 play）
> - **消耗**：爱尔兰至高王国战争参战花费凝聚力
> - **关联**：与爱尔兰任务及局势「统一爱尔兰」相关（后话）
> - 被入侵时**可参战部落数受凝聚力上限**约束——凝聚力低则只有少数部落下场（防止爱尔兰 16 部落全体压上，避免「英格兰 30 队 vs 192 队」的失衡）

> **爱尔兰至高王国至高王选举**：初始至高王为**蒂龙（内芙·奥尼尔）**。至高王**按期选举**，也可通过**外交博弈 / 战争**（夺取至高王 CB）变更。选举评分 = **国家实力（经济基础 + 军事）** + **主观评价** + **随机骰子加成**——最终由 **LLM** 综合参考决定（客观参考 + 主观演绎）。

> **海盗联盟（机制，经济型）**：平等海盗同盟——The Isles / 奥克尼 / 设得兰 三栖姬组成。
> - **战利品获取**：成员通过**劫掠**（海盗技能）掠夺沿海地块 / 商船 / 俘虏，产出**战利品（金币）**
> - **功勋**：按成功劫掠次数、战利品价值、俘虏数、俘获船数计算各成员**功勋**
> - **分配**：战利品**按功勋比例分配**——功勋越高分得越多；「献上猎物」是荣耀的象征
> - **经济作用**：战利品转化为成员的金币收入（可再投资劫掠、淫趴、扩张）
> - **维系**：**分赃公平**维系海盗联盟——若分配不公则生嫌隙（类比爱尔兰至高王国凝聚力，靠「利益均沾」维持）
> - 关系松散，主要经 LLM 演绎；引擎提供战利品数值参考

### 5. 附庸国互动 (Vassal Interactions)

> 附庸国互动并非单一机制，而是**随文化组而异的双向习俗**——既有益于宗主，也有益于附庸，绝非单方面索取。具体机制留待后续章节，此处先立原则与文化风味：

- **封建基本法**：领主**不能**直接永久没收附庸国后宫成员
- **君主制（人类宫廷）**：礼法式「朝贡」——附庸公主定期携后宫晋见宗主，于宫廷宴会与百合演出上展现后宫，换取宗主的恩宠与庇护（威望双向流动）
- **凯尔特部落（犬姬）**：「联盟之仪」换妻play——相邻氏族通过交换后宫成员共欢，以欢愉巩固血亲与誓约，提升部落凝聚力
- **海盗（塞壬）**：战利品共享——栖姬们共享掳来的战利品与俘虏，按功勋分配，以「献上猎物」彰显荣耀
- **神权制（圣女）**：待定

### 6. 局势（Situation）

> 局势是一个**进度条机制**（数值 0~100，分 **5 个阶段 I~V**），可增可减，与事件紧密相关——可由事件触发，阶段变化产生不同的历史事件或随机事件；达到 0 / 100（或特定阶段）时结算。

**机制要点**：
- **进度**：0~100 数值，随行动 / 事件 / 选择增减
- **阶段**：5 阶段（I~V），不同阶段解锁不同事件选项与效果
- **事件关联**：局势触发事件；不同阶段产生不同历史 / 随机事件
- **结算**：进度到 0 / 100（或阶段目标）时产生结果

**例子**：
1. **爱尔兰统一局势**（爱尔兰至高王国）：凝聚力满即可**统一爱尔兰**，统一会**消耗凝聚力**
2. **联合统治局势**：从「平等后宫」到「主奴 play」的谱系，初始在**阶段 III（平衡）**，向两侧移动
3. **百年战争局势**：英格兰及苏格兰参与的拉锯——**0 = 英国胜利、100 = 法国胜利**；**初始也在阶段 III（中间）**；频繁触发事件要求投入**兵力 / 经济 / 威望**；若拒绝，局势向另一侧偏移（增 / 减）

第三章：战争与俘虏 (War & Captives)

> **设计主轴**：战争不以**吞并**为主，而以**附庸化**为核心——战争条款主要围绕「建立附庸」展开。本作是让附庸越来越忠诚的**后宫养成游戏**：附庸即后宫成员，征服即「纳入后宫体系」。

### 1. 战斗本质：百合 Battle Fuck

本作**不采用躯壳重生 / 伤害机制**。战斗即百合 Battle Fuck——交战双方（扶她军团）以色情交锋决出胜负，直到一方**高潮失神**而败北。整个过程无真实伤害，只有快感的积累与崩溃。

- **每月结算**：战斗按月推进（通常数个月分出胜负）；双方各投 D10，对对方造成伤害 = **max(双方总士气) × 0.2 × (1 + 0.1 × 骰子)**；**总士气 = 基础士气(10) × 队数**；**不引入训练度**
- **无减员**：战斗不损失兵力（Battle Fuck 无伤害）——**胜负 = 打光对方士气**
- **士气恢复**：战斗结束后每月恢复 **+20% 最大士气**（上限 = 总士气）

### 3. 要塞（EU 规则）

- 要塞有**等级**（EU 概念，影响围城 / 防守，**不影响控制区范围**）
- 要塞**只控制周边一圈**（自身地块 + 相邻地块）
- **要塞控制区（Zone of Control, ZoC）**：处于敌方 ZoC 内时，军队移动受限（见下）

#### 3.1 返回省份（Return Province，归还省份 / 绿旗省份）

每个陆军单位在后台存一个「返回省份」变量：

- **定义**：进入敌方 ZoC **之前**，最后离开的**安全省份**（非 ZoC 陆地省份，或登陆时的海域格）
- **更新时机**：仅在军队**离开**一个非 ZoC 省份时更新（不是进入时）
- **清除条件**：若返回省份本身落入敌方 ZoC，则被自动清除
- **视觉**：选中 ZoC 内的军队时，绿旗指向返回省份

#### 3.2 基于返回省份的移动判定（路径独立）

移动判定不看你一路怎么走，而是算「目标省份 ↔ 返回省份」的距离（经有通行权且非 ZoC 的省份）：

- **距离 0（退回）**：总能直接移回返回省份（哪怕隔着要塞）
- **距离 1（相邻）**：总能移到与返回省份相邻的任意省份
- **距离 2（隔一格）**：若中间隔一个安全的非 ZoC 省份，可越过它移动
- **与要塞直接相邻**：总能移到相邻的敌方要塞省份（围攻）

#### 3.3 多要塞与特殊情况

- **控制区重叠**：进入被两座要塞同时控制的格，可任选其中一城围攻；但不能穿过重叠格走到要塞后方安全区；进入一城后（未攻陷）移动范围被限于「退回返回省份」或「移到另一座相邻要塞」
- **攻占要塞陷阱**：离开刚攻陷的要塞（已变非 ZoC）时，返回省份刷新为该要塞；若再走进另一要塞的 ZoC，可能被卡在敌后只能退回
- **首都**（含附庸首都）默认 **1 级要塞**
- 地图初始设有若干**初始要塞**

### 4. 战败与撤退

- 单次战斗**不决定胜负**——士气归零 → 战败方**后撤至首都**
- 若**在本方首都被打败**（士气归零且已撤回首都）→ **无条件投降**（即时）；首都**沦陷连续 ≥6 个月** → **自动投降**

### 5. 围城

- 围城军队须**驻留不动**，**每月判定一次**
- **破城概率 = 1 / (要塞等级 + 1)**
  - 等级 1 → 50%
  - 等级 2 → 33%
  - 等级 3 → 25%
- **要塞等级来源（可叠加）**：
  - 首都默认 **1 级**要塞（50%）
  - 地图初始要塞 **2 级**（33%）
  - 首都若同时有初始要塞 → 合计 **3 级**（25%，如爱丁堡）

### 6. 投降与议和（无战争分数，聊天驱动）

> 简化：**不做死的战争分数计算**。只有「攻破首都」这一硬性投降条件；其余议和全部走 LLM 聊天——玩家向敌国公主**随意提出条件**，对方按战况 / 性格 / 好感度判断是否同意，同意即和平。

**活的议和（其余情况）**：

**联盟战争**：
- 投降方为**主要至高王**

### 7. 宣战：外交博弈（简化为单阶段）

> 简化：**不做多阶段流程**——外交博弈只有**一个阶段**，**持续 2 个月**，期间双方可**随意调整**战争目标与条件，期满未谈拢即开战。

- **外交博弈为期 2 个月（单阶段）**：
  - **发起博弈**：提出**战争目标**（如吞并某地、要求附庸、政权更迭等）；相关方（含附庸 / 盟友）决定加入战局或**保持中立**
  - **期间随意调整**：2 个月内，双方随时可增改战争目标 / 附加索求 / 条件，无固定阶段
  - **退缩**：若一方退缩 → **付出战争目标**（对方不战而获，退缩方失威望）
  - **开战**：2 个月期满双方仍互不退让 → **战争爆发**
- **战争目标**定义战后可索要的内容（CB 决定可索要范围；议和时由对方公主 LLM 判断合理性）
- 与爱尔兰至高王国契合：对爱尔兰部落发起博弈时，至高王牵头的联盟在博弈期集结、站队
- **限制**：**不能对已在战争中的国家宣战**（发起外交博弈）；想参与某场战争，通过外交博弈加入某方

> **AI 国家的外交决策**：AI 国家的宣战 / 站队 / 退缩 / 提目标等外交动作，由「世界 AI」（LLM 扮演各国公主、过家家式）按月决定；玩家自己的外交经 UI 面板 / 聊天操作。

### 8. 战争理由（CB）与吃地规则

> 通用战争主要围绕**附庸化**展开；**直接吃地**仅限合法 CB（少而精）。

**可吃地的通用 CB**：
1. **收复失地（Reconquest）**：目标省份是本族 / 本文化**核心**却被外族占领——可直接吃这些核心省份，议和时更易达成。例：爱尔兰部落收复被英格兰 / 诺曼占领的爱尔兰省份。
2. **领土宣称（Claim）**：持有目标省份的**正规宣称**（历史宣称 / 继承 / 事件 / 正式授予，**不可随意伪造**）——可索要宣称省份。
3. **解放同族（Liberation）**：目标省份的同文化族裔受异族统治——目前目标为**康沃尔（Southwest）**、**苏格兰高地**；解放后按情况**近距离并入本国 / 远距离释放为附庸**。

**通用 CB vs 事件 CB**：
- **通用 CB（随时可用）**，随文化组而异：
  - **塞壬（诺斯）**：**附庸化 CB**——可对别国发动附庸化（塞壬较弱，不影响平衡）
  - **英格兰文化**：**仅受保护国 CB**——英格兰较强，不能随意附庸化
  - **凯尔特（犬娘）**：**夺取至高王地位 CB**——以「狗狗打斗」争夺至高王之位（交配权 / 后宫老大），可对爱尔兰至高王国成员发动；胜利者成为至高王
  - **附庸独立 CB**（所有附庸国通用，非文化专属）：可对宗主发动**独立战争**；**仅当对宗主好感度很低**时可使用
- **事件 CB（需事件 / 条件触发，非通用）**：
  - **联合统治**：需**事件**或**调教关系**触发
  - **威尔士起义（开局 1400.9）**：特殊 CB——可直接把**英格兰公主纳入后宫（联合统治）**，并有**独立条款**
  - **珀西叛乱（1403）**：诺森伯兰（珀西）叛乱的特殊 CB——对英格兰公主的**现任主人（联统方）**宣战；获胜可**联合统治英格兰公主**，或**转移联合统治权**（夺取既有联统）

第六章：经济与内政

### 军队
- **1 个单位 = 100 人**
- **军队上限**：国家初始上限 **5 队**（= 500 人）；**每一块直接统治的地 +2 队**
  - 例：1 块地 = 7 队｜苏格兰（6 块）= 17 队｜英格兰直辖（10 块）= 25 队
- **附庸税**：附庸国军队上限再**固定 -3 队**（向宗主纳贡 / 出兵后自有军力减少），防止附庸过多导致整体过强；例：1 块地附庸 = 4 队
- **附庸有各自军队上限**，宗主国只算**直接统治**的地块
- **上限含义**：上限即**招募上限**——达到上限后不能再招募士兵；**事件可给予超出上限的临时部队**（如开局威尔士叛乱的叛军）；**战争结束后解散回上限**
- **开局与招募**：开局金币 **20**、威望 **50**、军队 = 上限 **50%**；招募 1 队 **20 金**、**每月限 1 队**

### 收入
- **基础收入**：每年**税基 60** = 每月 **5 金币**（平衡大国 / 小国差距）
- **地块收入**：每块地按建筑产生——
  - **税收**（农场）
  - **贸易**（市场）
  - **卖淫**（妓院）

### 建筑（每块地）
| 建筑 | 产出 | 初始等级 |
|------|------|------|
| **农场** | 税收 | lv.1 |
| **市场** | 贸易 | lv.1 |
| **妓院** | 卖淫 | lv.1 |
| **要塞** | 防御（围城） | lv.0（无），除地图初始要塞 |

> 建筑收入：农场 / 市场 / 妓院每级每月产出 **0.3 金**（lv.1~4 = 0.3 / 0.6 / 0.9 / 1.2）

> 注：初始建筑等级可**按国家微调**（平衡性调整），如某些部落的地块初始农场 lv.2，使特定国家稍强。

### 威望（Prestige）

可**积累 / 消耗**，范围约 **-100 ~ +100**：

- **数值加成**（每 100 威望）：**+10% 士气**、**+10% 税收 / 贸易 / 卖淫收入**
- **外交加成**：高威望提高外交提议被接受率（结盟、联姻、附庸化提议）
- **AI 态度**：高威望令 AI 更尊重（参考因素）
- **消耗**：部分行动消耗威望（干预、策动、特殊外交，待定）
- **积累**：战争胜利、外交胜利、淫趴盛况、事件
- **衰减**：**每月衰减 5%**，向中间值自然回归

第七章：任务与事件系统

### 1. 任务树（Mission Tree）

标准任务树：按序 / 并行完成任务，完成获得奖励、解锁后续任务。

- **完成判定**：**程序判定**（条件满足）+ **LLM 输出 flag 完成**（避免错误卡死 / 意外情况）
- **主观任务**：可设完全主观的任务（如「向主人献媚」），由 LLM 判定完成
- **仅玩家生效**：任务树**只对玩家**；**LLM 控制的 AI 不做任务**

**任务格式**：
```
任务名：【任务名称】
以下条件必须满足（全部）：
- 完成任务【前置任务】
- 条件...
以下条件至少满足一个：
- 条件 A
- 条件 B
不是：
- 排除条件
奖励：
- 奖励内容
```

**示例：苏格兰任务【宣称英格兰】**
```
完成任务【百年战争的胜利】
所有省份：（苏格兰及群岛全部省份）属于苏格兰或其非保护国属国
以下条件至少满足一个：
- 军队规模大于英格兰
- 英格兰对苏格兰好感度大于 80
不是：
- 英格兰不存在
奖励：
- 联合统治英格兰（包括直接从现有联合统治中 NTR）
```
> 可加：LLM 可输出隐藏 flag 完成，避免意外情况。

### 2. 事件（Events）

事件对**玩家与 AI 均有效**。事件提供带**权重**的选项——玩家自行选择（UI / 聊天）；**AI 按权重自动选择**（引擎按权重结算，无需 LLM 点击）。

**三种事件**：
1. **历史事件（Historical Events）**：特定历史时刻 / 条件触发的一次性事件（如威尔士起义、珀西叛乱、教会大分裂）
2. **随机事件（Random Events）**：满足条件时从事件池随机抽取（如丰收、灾害、淫趴意外）
3. **脉冲事件（Pulse Events）**：周期性定时触发（如每月 / 每季 / 每年的例行事件）

**事件格式**：
```
事件名：【事件名称】
触发：条件 / 周期 / 随机权重
选项（带权重）：
- 选项 A（权重 X）：效果
- 选项 B（权重 Y）：效果
```
